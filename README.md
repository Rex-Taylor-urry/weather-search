# weather-search
天气预报查询页面
一个纯前端的天气预报查询页面，原生 HTML + CSS + JavaScript 实现，不依赖任何框架、不使用构建工具，双击 HTML 文件即可运行。
功能
实时天气展示：温度、空气质量（含等级）、风向风力、紫外线、湿度、日出日落时间
7 天天气预报：每天显示星期、日期、天气图标、天气文字、温度区间、风向风力
城市搜索：输入省份名自动查询该省份包含的城市，下拉列表点选即可切换城市
支持城市编码：直接输入 6 位城市编码查询，例如 210200 = 大连市
自封装 myAxios：基于 XMLHttpRequest + Promise 手写，模仿 axios 的 url / params / method / data 调用方式
直接用浏览器打开 天气查询.html 即可，无需安装任何依赖、无需启动服务器。
